# دَواك — Dawaak
### المنظومة الوطنية للرعاية الصيدلانية الذكية ورادار نواقص الأدوية في مصر
> **"دواك تلاقيه.. ويوصلك في ثواني"**

---

## 🌟 نبذة عن المشروع
منصة رعاية صحية رقمية متكاملة لربط الصيدليات المصرية المستقلة بسلاسل الإمداد والمرضى مباشرة بدون وسطاء، منافسة مباشرة لنماذج (Vezeeta / Chefaa / Talabat Mart)، بميزات نوعية ثورية تحل أزمات سوق الدواء المصري:

1. **رادار النواقص الذكي (Shortage Radar Mesh):**
   - شبكة جغرافية لحظية لكشف وتتبع الأدوية الحرجة والنادرة (مثل: Eltroxin, Clexane, Ozempic, Tegretol, Ventolin).
   - حجز فوري مؤقت لمدة 3 ساعات بالصيدلية المعتمدة مع كود QR.
   - إذا لم يتوفر الدواء، يتم بث تنبيه عاجل لجميع الصيدليات المسجلة داخل نطاق المحافظة/المدينة.

2. **ماسح ومفسر الروشتات بالذكاء الاصطناعي (AI Rx Handwriting Scanner):**
   - محرك رؤية حاسوبية مدعوم بـ **Gemini 2.0 Multimodal**.
   - فك طلاسم خط الأطباء المصريين واستخراج الأسماء التجارية، المواد الفعالة (Generics)، الجرعات، وتكرار الاستخدام.
   - اقتراح البدائل المعتمدة بنفس المادة الفعالة فوراً.

3. **مفسر التحاليل الطبية السريري (Lab Test AI Explainer):**
   - فحص وتفسير تقارير التحاليل المخبرية (صورة دم كاملة CBC، وظائف كبد، وظائف كلى، دهون ثلاثية، سكر تراكمي HbA1c).
   - استخراج الباراميترات ومطابقتها بالنسب الطبيعية المرجعية العالمية مع مؤشرات ملونة (طبيعي / منخفض / مرتفع).
   - صياغة أسئلة استرشادية موجهة للمريض ليطرحها على طبيبه المعالج، مع نصائح نمط حياة وتغذية مساندة.

4. **منظومة الـ White-Label للصيدليات (Pharmacy Multi-Tenant SaaS):**
   - واجهة متجر إلكتروني مستقلة ومخصصة لكل صيدلية شريكة (`/pharmacy/[slug]`).
   - لوحة تحكم فورية لإدارة الطلبات، تسليم الأوردرات لطياري الدليفري، ومتابعة التحصيل (`/dashboard`).
   - نموذج عمولة 0% على الأدوية المسعرة جبرياً من هيئة الدواء المصرية (EDA).

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework:** Next.js 16.4.3 (App Router, Turbopack & Webpack, React 19)
- **Database & ORM:** Neon Serverless PostgreSQL + Prisma 7 (مع المحول الحديث `@prisma/adapter-pg`)
- **AI Core:** Google Gemini 2.0 Flash Multimodal (تحليل الصور والروشتات والتحاليل)
- **Styling:** Tailwind CSS 4 + Lucide React Icons
- **Typography & Theme:** خط Cairo العربي الأصيل + تصميم Luxury HealthTech Glassmorphism (Dark & Light support)

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد قاعدة البيانات وتحديث الـ Schema
npx prisma db push

# 3. تغذية البيانات الأولية والأدوية المسعرة والصيدليات الشريكة
npx tsx scripts/seed_dawaak.ts

# 4. تشغيل خادم التطوير
npm run dev
```

التطبيق يعمل على: `http://localhost:3000` أو المنفذ المحدد.

## 📂 خريطة الصفحات الرئيسية
| المسار (Route) | الوظيفة |
| :--- | :--- |
| `/` | البوابة الرئيسية العامة، دليل أدوية مصر المسعرة، والصيدليات المعتمدة |
| `/radar` | رادار النواقص الذكي، حجز 3 ساعات، وبث طلبات البحث المباشرة |
| `/prescription` | فاحص وماسح الروشتات بالذكاء الاصطناعي وبدائل الأدوية |
| `/lab-analyzer` | مفسر نتائج التحاليل المخبرية والطبية السريرية |
| `/pharmacy/[slug]` | المتجر الرقمي المستقل لكل صيدلية شريكة وقائمة المخزون والدليفري |
| `/dashboard` | لوحة تحكم الصيدلي، أسطول الطيارين، وتحديث حالات الطلبات |
